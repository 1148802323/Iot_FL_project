
把下面整段代码复制进去：

```python
"""Export final validation/test probabilities for the shared evaluator."""

from pathlib import Path

import numpy as np
import pandas as pd


def export_final_predictions(
    output: Path,
    full_data: pd.DataFrame,
    validation_indices: np.ndarray,
    test_indices: np.ndarray,
    models_by_strategy: dict[str, dict[str, object]],
    features: list[str] | tuple[str, ...],
    seed: int,
) -> None:
    rows: list[dict[str, object]] = []

    for strategy, model in models_by_strategy.items():
        coefficients = model["coefficients"]
        weights = np.asarray(
            [model["intercept"], *[coefficients[name] for name in features]],
            dtype=float,
        )

        for split, indices in (
            ("validation", validation_indices),
            ("test", test_indices),
        ):
            subset = full_data.iloc[indices]
            matrix = np.column_stack(
                [
                    np.ones(len(subset)),
                    subset.loc[:, list(features)].to_numpy(dtype=float),
                ]
            )
            probability = 1.0 / (
                1.0 + np.exp(-np.clip(matrix @ weights, -35.0, 35.0))
            )

            rows.extend(
                {
                    "UDI": int(identifier),
                    "seed": seed,
                    "strategy": strategy,
                    "split": split,
                    "probability": float(value),
                    "round": 0,
                }
                for identifier, value in zip(subset["UDI"], probability)
            )

    output.parent.mkdir(parents=True, exist_ok=True)
    new_rows = pd.DataFrame(rows)

    if output.exists():
        previous_rows = pd.read_csv(output)
        previous_rows = previous_rows[previous_rows["seed"] != seed]
        new_rows = pd.concat([previous_rows, new_rows], ignore_index=True)

    new_rows.sort_values(
        ["seed", "strategy", "split", "UDI"]
    ).to_csv(output, index=False)
```

如果 GitHub 里已经有 `src/evaluator_export.py`，不需要再次新建，直接使用即可。

## 第 4 步：运行 5 个随机种子

在项目根目录打开 PowerShell，只运行自己负责的脚本。

FedAvg：

```powershell
42,52,62,72,82 | ForEach-Object { python .\src\train_fedavg_baseline.py --seed $_ }
```

Variant 1：

```powershell
42,52,62,72,82 | ForEach-Object { python .\src\train_failure_aware_fedavg.py --seed $_ }
```

Variant 2：

```powershell
42,52,62,72,82 | ForEach-Object { python .\src\train_failure_count_fedavg_variant2_clean.py --seed $_ }
```

每次运行新 seed 时，导出工具会保留其他 seed，只替换当前 seed 的旧数据。因此不要在五次运行之间删除 CSV。

## 第 5 步：把 CSV 发给 evaluator 负责人

运行结束后，只需要提交自己的一个 CSV：

```text
reports/evaluator_exports/fedavg.csv
reports/evaluator_exports/failure_aware_v1.csv
reports/evaluator_exports/failure_aware_v2.csv
```

打开 CSV 后，第一行必须是：

```text
UDI,seed,strategy,split,probability,round
```

文件应同时包含：

- seeds：`42`、`52`、`62`、`72`、`82`；
- strategies：`iid`、`moderate_non_iid`、`highly_non_iid`；
- splits：`validation`、`test`；
- probability：范围为 0 到 1。

## Evaluator 负责人运行下面的命令

所有 CSV 收齐后，在项目根目录运行：

```powershell
python .\standalone_non_iid_evaluator.py `
  --prediction fedavg=.\reports\evaluator_exports\fedavg.csv `
  --prediction variant_1=.\reports\evaluator_exports\failure_aware_v1.csv `
  --prediction variant_2=.\reports\evaluator_exports\failure_aware_v2.csv `
  --prediction adaf2avg=.\part4_outputs\linear\adaf2avg_predictions.csv `
  --baseline fedavg `
```

